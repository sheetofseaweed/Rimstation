code/datums/map_config.dm

/proc/load_default_map_configProc that simply loads the default map config, which should always be functional.
/proc/trim_trailing_slashesProc handling the loading of map configs. Will return the default map config using /proc/load_default_map_config if the loading of said file fails for any reason whatsoever, so we always have a working map for the server to run. Arguments:
/proc/is_whitelisted_map_directoryTRUE when directory is a whitelisted map root, or a save folder inside the persistence root.
