rimstation_overworld_route
/datum/unit_test/rimstation_overworld_route

Route planning, on ground the test controls completely.

Generated regions are deliberately not used for the arithmetic here. A route test that ran over random terrain would be asserting whatever that seed happened to produce, and would go green for the wrong reason the moment the generator changed. So each of these flattens the region first and then builds the exact obstacle it is about.
