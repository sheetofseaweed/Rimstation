stash_never_duplicates
/datum/unit_test/rimstation_colonist_chapter/stash_never_duplicates

The same item is never declared twice, whatever the assignment says.

This is the failure that would quietly ruin a colony: two containers both believing they hold a colonist would each write a map block for the same worn items, and the colony would come back with two of everything. Exclusive assignment is only correct while the assignment logic is correct, so the guard does not trust it.
