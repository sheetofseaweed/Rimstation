persistence_shuttle_underlying_area_saved
/datum/unit_test/persistence_shuttle_underlying_area_saved

A shuttle tile records the ground it is parked on, because only the port knows and the port is not saved.

A shuttle gives each turf back to that area when it lifts off. Without this the restored shuttle falls back to its dock's area_type, which for a home dock was read off the shuttle sitting on it - so taking off would leave a patch of shuttle floor behind instead of the ground.
