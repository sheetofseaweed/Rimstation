rimstation_overworld_region
/datum/unit_test/rimstation_overworld_region

Shared scaffolding for region tests.

Every test builds its own region from a fixed planet, because the point of the region is that it is derived rather than stored - two builds from the same inputs have to agree, and a test that reused one region could not tell that apart from a region that simply never changes.
