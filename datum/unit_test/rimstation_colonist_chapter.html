rimstation_colonist_chapter
/datum/unit_test/rimstation_colonist_chapter

Shared setup for tests that drive SScampaign's roster.

These tests run against the live subsystem, because the roster's whole job is to be the thing SScampaign carries between chapters, and a copy of it proves nothing about that. Everything the subsystem owned before the test is put back afterwards, or the next test in the suite inherits a colony it never asked for.

Vars

saved_overworldThe region and the accounts. Borrowed like the rest, because a test that forms an expedition or spends the colony's food would otherwise leave both behind for whatever test runs next.

Procs

begin_test_campaignPuts SScampaign on a throwaway campaign with an empty roster, and returns its manifest.
