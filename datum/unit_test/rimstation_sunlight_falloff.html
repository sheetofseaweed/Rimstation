rimstation_sunlight_falloff
/datum/unit_test/rimstation_sunlight_falloff

Falloff drops with distance and never leaves 0..1.

The maths is a softened cone. If it ever returns above 1 the colour matrix saturates and a doorway looks brighter than open ground, which reads as a bug in the roof code rather than in this one line.

Uses dummy corners with hand-set coordinates. Real corners register themselves onto the four turfs around them, so building two here would detach the map's own corners and quietly break lighting for every test that ran afterwards.
