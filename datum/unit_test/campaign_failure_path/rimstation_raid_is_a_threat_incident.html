The storyteller can buy a raid, and a raid is what it gets.

Raids were startable only from an admin verb, which meant the colony's central threat was the one thing the storyteller could not pace. Making a raid an incident hands it the budget, the tracks, the repetition weighting and the recovery rule that every other colony event already goes through.
