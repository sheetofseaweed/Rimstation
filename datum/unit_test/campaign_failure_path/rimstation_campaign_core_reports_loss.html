rimstation_campaign_core_reports_loss
/datum/unit_test/campaign_failure_path/rimstation_campaign_core_reports_loss

The colony core reports a loss into whatever chapter is running, without being told about it.

A core is placed during mapload, long before a chapter exists, so anything that assigned the chapter record at creation time would capture null and silently never resolve. That failure is invisible in isolation - the core works perfectly, it just reports to nobody - so the connection is asserted from both ends.
