campaign_failure_path
/datum/unit_test/campaign_failure_path

Shared scaffolding for the four ways a chapter can stop.

Each of these drives the real subsystem, so each has to hand it back exactly as it found it. A failed assertion returns from Run() immediately, so the restore lives in Destroy() where it cannot be skipped.

Vars

saved_clock_originThe live campaign clock's origins. Runtime-only subsystem state, so it is borrowed and returned like the rest - a test that began a chapter has rebased them onto its own campaign.
saved_pointerRaw pointer file contents. It names which campaign the server runs, so it lives outside any campaign directory and would survive this test's cleanup, redirecting a real boot at a deleted test campaign.
test_campaign_idCampaign id this test owns. Everything it writes lives under it and is deleted with it.

Procs

commit_one_chapterPlays one chapter to a successful commit, leaving a committed checkpoint for the test to work against.
take_campaignPuts SScampaign into a known empty state and takes custody of it for the duration of the test.
