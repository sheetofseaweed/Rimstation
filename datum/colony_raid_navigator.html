colony_raid_navigator
/datum/colony_raid_navigator

Route maps for one raid: an upstream path map per destination, built with the same passability rules as JPS. A build costs ~0.6 s CPU on the colony map, so it runs in capped slices; SSpathfinder would stall other mobs.

Vars

buildsBuilds in progress keyed by destination turf, oldest first.
mapsFinished maps keyed by destination turf.
maps_builtMaps finished over the raid's life, for the admin readout.
pass_infoPassability for every map. Taken from the raider type, because the first map is needed before any raider exists.
requested_atWhen each finished map was requested, keyed by destination turf. A map shows the world as it was then.
