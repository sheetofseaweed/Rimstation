rimstation_set_overworld_site_state
/datum/admin_verb/rimstation_set_overworld_site_state

Marks a site available, resolved or depleted.

This is also how a site is retired: depleting one is what play does to a site that is finished with, and a generated site cannot be deleted because the generator would put it straight back on the next build.
