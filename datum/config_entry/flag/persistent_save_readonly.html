persistent_save_readonly
/datum/config_entry/flag/persistent_save_readonly

Load saved worlds as normal, but never write new ones.

For local testing. A test round that writes a save leaves it to be restored over the next round - including unit test runs, where a restored world silently replaces the map's areas and fails unrelated tests.
