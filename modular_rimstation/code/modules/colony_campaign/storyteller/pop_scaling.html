MUNDANE_POP_SCALE_THRESHOLD

Population scaling for storyteller event frequency.

Upstream shipped this as dead code - the vars and config entries existed, nothing read them - and has since deleted it. We read it: get_population_frequency_multiplier() is part of how add_points() paces a track, so the storage it needs lives here rather than back in the upstream file that dropped it.

A colony round is small, so the penalty is what keeps a three-person settlement from being paced like a full station. Turn it off with ALLOW_STORYTELLER_POP_SCALING in config/bubbers/storyteller.txt. Pop at which a track stops being penalised. Below it the penalty eases in towards the full amount.
