# Rimstation flora asset provenance

The following unmodified DMI files were copied from
[Civ13](https://github.com/Civ13/Civ13) at commit
`ea9d74c155975889c09707cd60e2a80a2f24078c`:

- `civ13_bigtrees.dmi`, originally `icons/obj/flora/bigtrees.dmi`;
- `civ13_pinetrees.dmi`, originally `icons/obj/flora/pinetrees.dmi`;
- `civ13_wild.dmi`, originally `icons/obj/flora/wild.dmi`;
- `civ13_berries.dmi`, originally `icons/obj/flora/berries.dmi`.

Civ13 distributes these files with its codebase under the GNU Affero General Public License version 3, the
same license used by Rimstation. Only the artwork was copied; Rimstation's DM definitions and behavior were
implemented against this codebase's current flora APIs.
